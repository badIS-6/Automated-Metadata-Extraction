# Automated Metadata Extraction Pipeline

A customizable R pipeline for automatically extracting catalog-level metadata from collections of datasets.

Extracts:
- Category name
- Dataset counts and formats
- Sub-categories (keywords)
- Units
- Geographic coverage
- Years covered
  
and outputs a single `Metadata.csv`.

### To customize:

Change: dir, categories names, publishers and analysts, geographic names

Keep: stopwords, functions and tools
